Base vs LoRA comparison clips - Stable Audio 3 Small

These 24 clips were generated on the Hawk cluster with compare_lora.py from
the MusicLLM repo. Each genre folder holds three prompts, each generated twice
with the same seed:

  promptN_base.wav  base model (small-music) with the LoRA at strength 0,
                    which switches it off completely
  promptN_lora.wav  same prompt and seed with the genre's LoRA at strength 1

The seed equals the prompt number (prompt0 = seed 0, prompt1 = seed 1,
prompt2 = seed 2), so within a pair the LoRA is the only setting that changes.
All clips: 8 sampling steps, CFG scale 1.0, 30 seconds, 44.1 kHz stereo.

The prompts are worded like the LoRA training captions, which were built from
Jamendo genre, instrument, mood and tempo tags.

  prompt0: Instrumental rock, featuring electric guitar, drums, bass, energetic mood, fast tempo
  prompt1: Instrumental rock with indie influences, featuring electric guitar, melancholic mood, medium tempo
